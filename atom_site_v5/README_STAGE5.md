# Этап 5 — чистка тел public/contextual атомов

## Задача

Убрать из тел заметок служебные блоки, которые попадают в краткие описания статей и провоцируют модель на энциклопедический слоп.

Тело заметки теперь должно быть человеческим описанием смысла, а не внутренней картой графа. Служебные поля остаются во frontmatter: `visibility`, `role`, `routes`, `surface_policy`, `actions`, `allowed_claims`, `forbidden_claims`.

## Что сделано

- Очищены тела public/contextual атомов с блоками `Связанные элементы графа`, `## Связи`, `## Следующие действия`.
- Убраны wikilinks из очищенных тел: ссылки остаются во frontmatter, а тело используется как чистая текстовая основа для описаний и статей.
- Если после удаления служебных блоков оставался слишком тонкий текст, тело было пересобрано из `summary`, `user_problem`, `input`, `output` без служебных формулировок.
- Внутренние атомы не превращались в публичные тексты: их слой управляется через `visibility` и `surface_policy`.
- Пересобраны `data/atoms.json` и `data/atoms_v5.json`.

## Почему остатки во всех слоях могут оставаться

Часть служебных блоков может оставаться в `internal` атомах. Они не должны показываться пользователю и не должны становиться ссылками в публичных статьях. Для генерации публичных текстов критичен показатель `residual_public_contextual_noise_or_wikilinks`.
