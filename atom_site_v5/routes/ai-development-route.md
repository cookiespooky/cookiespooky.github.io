# Маршрут: AI-разработка и технический прототип

Этот маршрут используется только когда пользователь явно говорит про AI, LLM, агента, автоматизацию, модель, Codex, работу с репозиторием или техническую сборку.

## Основной путь

[[ai-development]] → [[technical-spec-from-idea]] → [[prompt-brief]] → [[context-package]] → [[ai-product-prototype]] → [[lead-ai-development]]

## Альтернативные ветки

- [[llm-apps]] → [[llm-backend]] → [[tool-calling]] → [[ai-product-prototype]]
- [[ai-agents]] → [[browser-automation]] → [[human-in-the-loop]]
- [[repo-map]] → [[ai-assisted-refactoring]] → [[codex]]

## Главное действие

[[lead-ai-development]] — когда нужно превратить идею AI-инструмента, автоматизации или технического продукта в понятный первый прототип или ТЗ.

Важно: общий MVP не надо автоматически называть AI-прототип. Для обычной проверки идеи используется маршрут [[startup-hypothesis]] → [[demand-validation]] → [[mvp]] → [[lead-startup-diagnostic]].
