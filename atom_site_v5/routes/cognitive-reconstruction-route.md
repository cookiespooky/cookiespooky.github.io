# Маршрут: Когнитивная реконструкция → Карта ситуации → Точка действия

Цель маршрута — провести пользователя от общего интереса к методу до понятного следующего действия.

## Основной путь

[[cognitive-reconstruction]] → [[source-material]] → [[graph-mapping]] → [[situation-graph]] → [[cognitive-gaps]] → [[action-point]] → [[reconstruction-session]] → [[lead-cognitive-reconstruction]]

## Альтернативный путь через заметки

[[diary]] → [[source-material]] → [[material-to-map]] → [[atomic-notes]] → [[situation-map]] → [[lead-notes-analysis]]

## Альтернативный путь через сценарии

[[understand-but-do-not-act]] → [[scenario-detection]] → [[repeating-scenarios]] → [[agency]] → [[action-point]] → [[lead-cognitive-reconstruction]]

## Главные действия

- [[lead-cognitive-reconstruction]] — если пользователь хочет разобрать текущую ситуацию.
- [[lead-notes-analysis]] — если пользователь пришел через Obsidian, дневник или заметки.
- [[lead-product-choice]] — если пользователь пришел через выбор направления или продукта.
