# Atom site v3

Это копия корпуса после этапа 3: ручная переработка ядра атомов.

Основные изменения:
- 27 ключевых атомов переписаны как человекочитаемые краткие смысловые описания.
- Служебная информация остается во frontmatter.
- Тела заметок не содержат “лидовое действие”, `role`, `visibility`, `surface_policy` и блоков “Связанные элементы графа”.
- `data/atoms.json` и `data/atoms_v3.json` пересобраны из Markdown.
