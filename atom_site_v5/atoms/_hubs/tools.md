# Инструменты

- [[ai-agents|AI-агенты]] — Системы, где модель выполняет последовательность действий с учетом цели, инструментов и обратной связи.
- [[llm-apps|LLM-приложения]] — Приложения, в которых языковая модель работает с контекстом, данными и действиями пользователя.
- [[obsidian|Obsidian]] — Локальная среда для заметок, связей, графа знаний, дневника и личной базы данных.
- [[knowledge-graph|Граф знаний]] — Сеть связанных понятий, заметок, продуктов, методов, кейсов и отношений между ними.
- [[diary|Дневник]] — Поток личных наблюдений, событий, мыслей и решений, который со временем становится материалом для анализа.
