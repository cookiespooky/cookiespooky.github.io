# Вектор смысла

Вектор смысла — направление, которое делает отдельные решения частью одной траектории. Он не заменяет план, но помогает выбирать между вариантами, когда все они выглядят потенциально ценными. В продуктовой работе такой вектор помогает не распыляться между несовместимыми версиями будущего.

Связанные атомы: Смысл, Выбор продукта, Философия действия, Когнитивная реконструкция.
