# Опорный контент

Контент, который формулирует основные идеи, методы, продукты и повторяющиеся проблемы аудитории. Он задает смысловой каркас для остальных публикаций.

Связанные элементы графа: [[content-system]], [[positioning]], [[offer]], [[peripheral-content]].

## Следующие действия

- **Проверить позиционирование** → [[positioning]]: Поможет понять, на какую роль автора должны работать опорные темы.
- **Связать с оффером** → [[offer]]: Поможет сделать контент не просто умным, а ведущим к понятному действию.
- **Собрать карту опорных тем** → [[lead-content-map]]: Поможет выбрать темы, которые удерживают всю систему.
