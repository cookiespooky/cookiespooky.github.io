## Задача

Claude нужен каждый день: в браузере, в приложении, в Claude Code. Отправлять через другой сервер весь
компьютер неудобно — банки, почта и местные сервисы начинают капризничать. Нужно, чтобы через свой сервер шёл
только Claude и несколько выбранных сайтов, а всё остальное работало как обычно.

## Что сделано

**Значок у часов.** Программа живёт в строке меню на Mac и у часов на Windows. Верхняя карточка — выключатель:
нажали, и Claude идёт через ваш сервер.

**Сервер настраивается из программы.** Достаточно адреса сервера и пароля от него: программа сама ставит на
сервер всё нужное, создаёт ключ для входа, и дальше пароль не нужен. Пароль нигде не сохраняется.

**Только выбранное идёт через сервер.** Claude — сайт, приложение и Claude Code — включён сразу. Остальные сайты
добавляются списком в настройках. Всё, чего нет в списке, работает напрямую.

**Понятно, что сломалось.** Каждая проверка — отдельной строкой: зелёная, если всё в порядке, красная — с тем,
что случилось и что сделать.

## Как работает

Программа держит защищённое соединение с вашим сервером и открывает на компьютере свой адрес для выхода через
него. Разные программы попадают туда по-разному:

- **Браузер и приложение Claude** — по списку сайтов, который Proxy Tunnel передаёт системе. Сайты из списка
  идут через сервер, остальные — напрямую.
- **Claude Code** — через свой файл настроек: Proxy Tunnel сам вписывает туда адрес, и Claude Code идёт через
  сервер целиком, кроме российских сайтов.
- **codex и gemini в терминале** (на Mac) — через несколько строк в настройках терминала, которые вписывает
  Proxy Tunnel. Работает в окнах терминала, открытых после этого.
- **VS Code** (на Mac, по желанию) — расширение Codex через посредника Proxy Tunnel или весь VS Code целиком.

Точка у значка в строке меню показывает состояние: зелёная — всё через туннель, жёлтая — туннель работает с
оговоркой (браузер идёт не через него), красная — туннель выключен или не работает.

Туннель выключили или закрыли программу — всё это снимается, и компьютер работает как без неё. Если туннель
включён, а связь с сервером оборвалась, Claude Code, codex, gemini и сайты из списка не уходят напрямую, а не
открываются: напрямую с российского адреса они не пойдут.

## Что идёт через сервер

- **claude.ai и приложение Claude** — да, по списку сайтов.
- **Claude Code в терминале и в VS Code** — да, целиком.
- **ChatGPT, Gemini и AI Studio в браузере** — да, по списку сайтов: они в нём уже есть.
- **codex и gemini в терминале** — на Mac да, сами. На Windows — если запускать их командой
  `$env:HTTPS_PROXY="http://127.0.0.1:8888"; codex`.
- **Расширения VS Code** (на Mac) — по выбору в настройках: только Codex или весь VS Code со всеми
  расширениями. Сначала обе галочки выключены.
- **Остальное** — напрямую.

Каждая строка — своей галочкой в настройках: Claude Code, codex и gemini включены сразу, VS Code — по желанию.

## Ограничения

- **Программа, которая пускает весь интернет компьютера через себя**, отменяет список сайтов: пока она запущена,
  браузер и приложение Claude идут через неё, а не через ваш сервер. Proxy Tunnel показывает это жёлтой
  строкой: это не поломка, туннель работает.
  Claude Code и codex с gemini в терминале это не касается — они идут через ваш сервер и в этом случае.
- **Сервисы определяют страну не только по адресу**: ещё по стране в аккаунте, способу оплаты, номеру телефона.
  Программа меняет только адрес, с которого идут запросы.
- **Gemini в браузере** грузится ещё и с общих адресов Google. Если он открывается не до конца, в список добавляют
  `google.com`, `googleapis.com` и `gstatic.com` — тогда через сервер пойдут и поиск, и почта Google.
- **Codex в VS Code** держится на служебной настройке расширения: после его обновления может перестать работать —
  программа это покажет. **Весь VS Code** через сервер — только если открыть его при включённом туннеле; выключили
  туннель при открытом VS Code — он останется без сети до перезапуска.
- **На Windows** codex и gemini в терминале — только командой выше.
- **Программа не заверена у Apple и Microsoft**: при первом запуске система переспросит. На Mac — правый щелчок по
  программе → «Открыть», на Windows — «Подробнее» → «Выполнить в любом случае».

## Как начать

1. Скачайте программу для Mac или Windows — ссылки выше.
2. Нужен свой сервер за границей с Ubuntu или Debian; если его нет, в программе есть кнопка «Арендовать сервер».
3. Впишите адрес сервера, нажмите «Настроить сервер», затем нажмите на верхнюю карточку.

Подробная инструкция — в [описании на GitHub](https://github.com/cookiespooky/proxy-tunnel).
