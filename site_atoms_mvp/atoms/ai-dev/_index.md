# ai-dev

- [[ai-agents|AI-агенты]] — Системы, где модель выполняет последовательность действий с учетом цели, инструментов и обратной связи.
- [[ai-development|AI-разработка]] — Создание продуктов и рабочих процессов, где LLM используется как часть системы, а не декоративная кнопка.
- [[full-stack-mvp|Full-stack MVP]] — Рабочая минимальная версия продукта с интерфейсом, логикой, данными и базовой инфраструктурой.
- [[llm-apps|LLM-приложения]] — Приложения, в которых языковая модель работает с контекстом, данными и действиями пользователя.
- [[llm-site|LLM-сайт]] — Сайт, где модель использует граф знаний для генерации текста, ссылок и маршрутов пользователя.
- [[vibe-coding|Vibe coding]] — Разработка через быструю итерацию с AI, где человек управляет направлением, а модель ускоряет реализацию.
- [[automation|Автоматизация]] — Передача повторяющихся действий системе, скрипту, интеграции или AI-агенту.
- [[prompt-engineering|Промпт-инжиниринг]] — Проектирование инструкций, контекста и формата работы модели для стабильного результата.
