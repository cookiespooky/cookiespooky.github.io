# Self-tracking

Self-tracking помогает увидеть закономерности, которые трудно заметить по памяти. Можно отслеживать настроение, энергию, решения, контент, продажи, задачи, отношения и контекст. В связке с дневником и графом знаний self-tracking превращает личные наблюдения в материал для анализа.
