# Стартовый граф сайта

Архив содержит главную страницу и стартовый набор атомов в формате Markdown для Obsidian, SEO и LLM-навигации.

## Структура

- `Главная.md` — человекочитаемая главная страница.
- `atoms/` — атомарные заметки по категориям.
- `data/atoms.json` — машинный индекс атомов и связей.

## Формат атома

Каждый атом содержит YAML frontmatter, короткий объективный текст, ссылки на связанные атомы и возможные следующие действия.

Ссылки сделаны в формате Obsidian `[[atom-id]]`, поэтому архив можно открыть как vault и сразу увидеть граф.
